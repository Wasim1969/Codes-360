# Codes 360
Open index.html in Chrome or Edge. For reliable persistence use a consistent HTTPS GitHub Pages address or local web server. Browser localStorage retains changes on the same origin/profile; clearing site data or switching devices can lose them. Export backups regularly. No server synchronization. The seed database contains all 850 rows of the reclassified workbook, not independently reconciled against screenshots. Truncated and OCR-derived wording must be verified. Automatic specialty detection is a limited keyword suggestion; manually confirm it. Do not publish internal insurance data publicly without authorization.

## GitHub Pages
Create a repository, upload the contents of this folder to its root, commit, then Settings > Pages > Deploy from a branch > main / (root) > Save. Repository visibility and Pages access depend on account settings. No external libraries or API keys required.
